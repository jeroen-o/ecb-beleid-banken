# ECB-beleid banken: van regelwijziging naar kantoorproces

Materiaal voor de informatieronde acceptatievoorwaarden hypotheken (november 2026, organisatie DFO BV).

- **[Startpagina](https://jeroen-o.github.io/ecb-beleid-banken/)** (`index.html`): kies Presentatie of Toolkit.
- **[Presentatie Dennes Roes](https://jeroen-o.github.io/ecb-beleid-banken/presentatie.html)** (`presentatie.html`): bedrijfsvoering in 7 vragen, met de eerste doelgroep 50–57 jaar. Toetsen: ←/→ bladeren, N notities, P handout, F volledig scherm.
- **[Alle marketingmaterialen](https://jeroen-o.github.io/ecb-beleid-banken/adviseurstoolkit.html#overzicht)**: overzicht met kalender en checklist vóór publicatie.
- **[Adviseurstoolkit](https://jeroen-o.github.io/ecb-beleid-banken/adviseurstoolkit.html)** (`adviseurstoolkit.html`): kantoorgegevens en logo, LinkedIn-campagne, jaarlijkse update en nazorgscan, klanttekst "Hypotheek vanaf 52 jaar" en nieuwsbrief.

Alles is standalone HTML: geen build-step, geen externe API's en geen opslag in de browser.
Stand van zaken: 18-11-2026. Bankbeleid kan wijzigen. Dit is algemene informatie, geen juridisch of fiscaal advies.
